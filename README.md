\# Coding Quiz



یه سایت که کاربرا سوال برنامه‌نویسی جواب میدن و امتیاز میگیرن.



\## مشکل چیه؟

یادگیری برنامه‌نویسی حوصله‌سربره. با بازی و رقابت، آدم‌ها بیشتر تمرین میکنن.



\## چی داره؟

\- ثبت‌نام و ورود

\- سوال برنامه‌نویسی

\- امتیاز و سطح

\- لیست بهترین‌ها



\## با چی ساخته میشه؟

\- Python

\- FastAPI

\- PostgreSQL

\- Redis
